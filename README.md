# PC Remote — Landing Page

Landing page do PC Remote, reconstruída em React 19, TypeScript e Vite. A interface usa CSS próprio, sem framework visual ou biblioteca de animação; o preview de pareamento e a faixa SAS são ilustrações de interface.

## Desenvolvimento

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
npm run preview
```
